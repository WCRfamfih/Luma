Luma / 流光 v1.1.0：更新默认效果，新增可切换的窗口置顶。

### 更新

- 将当前调好的视觉参数设为出厂默认：505px、细腻粒子档、1.2px 粒子尺寸，内部密度 5%、内部亮度 30%、光晕范围 1.75×、鼓点呼吸 2×。完整数值见仓库默认参数文件。
- 托盘右键菜单新增 **置顶**，默认开启，可独立于鼠标穿透开关。取消后允许其他窗口覆盖；调整大小、其他参数或重启均保持你的选择。
- 出厂默认关闭鼠标穿透，可直接拖动；需要穿透时从托盘菜单开启。

### 更新与下载

先从托盘退出旧版本，再替换 EXE。已有设置自动保留；如需采用整套新预设，在网页设置中点击「恢复默认」。旧版本没有置顶字段时，升级后默认开启置顶。

- **Luma.exe**：64 位主程序，Windows 10/11。
- **Luma-x86.exe**：32 位兼容版本。
- **Luma-1.1.0-Windows.zip**：双架构、说明、MIT 许可证与校验文件。
- **SHA256SUMS.txt**：EXE 的 SHA-256 校验值。
