Luma / 流光的首个公开版本。一个让系统声音化为桌面粒子光环的轻量 Windows 小工具。

### 下载

- **Luma.exe**：64 位主程序，下载后双击即可运行。
- **Luma-x86.exe**：32 位兼容版本。
- **Luma-1.0.0-Windows.zip**：两个版本、说明、MIT 许可证与 SHA-256 校验文件。
- **SHA256SUMS.txt**：两个 EXE 的校验值。

### 功能

- 原生透明置顶悬浮窗、托盘菜单、鼠标穿透与拖动缩放。
- WASAPI 系统音频采集，连续三维粒子游转、弹性鼓点响应与不规则海浪。
- 快速衰减的大气 Bloom、鼓点呼吸、局部密集炙热发白。
- 保留颗粒的亚像素覆盖与 FXAA 抗锯齿。
- 本地网页「简易 / 高级」实时调参，冰川蓝出厂配色，自动保存。
- 静态链接、无需安装额外运行时，单个 EXE 小于 1 MB。

### 开始使用

双击程序会打开设置页，播放系统声音或启用演示模式。默认开启鼠标穿透；需要移动时，从托盘右键菜单取消锁定。关闭网页不退出程序，退出请使用托盘菜单。

支持 Windows 10/11，目标为 Direct3D feature level 11。本版未签名；Windows ARM 未实机验证。完整图形和真实音频检查已在开发机运行，跨设备性能取决于硬件与参数。
